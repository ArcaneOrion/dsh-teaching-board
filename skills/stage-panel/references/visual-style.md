# 默认视觉风格

默认是“本地飞船控制台”风格：蓝灰科幻底、高对比黄色、粗黑漫画描边。它只是**可替换的皮肤**——任务语义优先，不合身就换。

## 方向

- 保留硬朗黑色描边和卡通块面。
- 黄色是主识别色和注意力颜色，保持强对比。
- 背景使用更明亮的蓝灰/孔雀蓝，不回到大面积黑色。
- 科幻感来自细网格、扫描线、状态灯和 HUD 小标签，不使用夸张光晕。
- 小圆角，避免柔软 pill-heavy UI。
- 面板自己就是主区域：不要在一个面板里再模拟出“左侧栏 + 底部输入”的旧 shell 布局。

## 布局

```text
紧凑顶部状态栏（可选）
主信息区（占满面板）
底部选项栏：只在 stage_choice 时出现
```

面板内容不被强制套用固定风格：可以拥有自己的视觉语言，但默认应呼应蓝灰科幻底、黄色高亮和漫画描边。

布局默认值：

- 如果做顶部状态栏，控制在 ~52px 以内。
- 主信息区占满面板；不要为未激活的选项预留空白。
- 辅助说明后置或可折叠，不占主信息的位置。
- 移动端优先保证主信息可读。
